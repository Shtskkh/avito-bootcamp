Решение задачи по классификации ботов

+ [data_inspection.ipynb](./data_inspection.ipynb) - блокнот исследования данных.

## Идея решения

Первоначальное исследование и идея предполагала,
что наибольший прирост будут давать признаки,
посчитанные для определённой куки: количество собитый, их расположенность во времени,
признаки, построенные из user_agent.

Применение per cookie вычислений не позволило поднять итоговую метрику выше, чем 53%.

Затем пришла идея, что можно смотреть не per cookie, а на cross cookie, то есть насколько
действия одной cookie с другими, и это позволило перейти порог итоговой метрики в 70% на тренировочной выборке,
а на тестовой в 66%.
